<objective>
Wire the fallback signal from Plan 08-02 through to the user: a warning banner above the pre-upload group cards when the SSE stream emits a fallback event, and an equivalent toast on the workspace "Sort Variants" path when the JSON response carries `fallbackUsed: true`. Record the `COHERE_API_KEY` deployment prerequisite in STATE.md so the deploy does not silently break, and close the phase with a human verification checkpoint that exercises both paths end-to-end.

Purpose: Plan 08-02 rewrote the server path but the client still silently consumes groups. Without a banner the user never learns that grouping degraded, which is exactly the UX trust hole 08-CONTEXT.md explicitly calls out. This plan closes that loop and pins the deploy-prerequisite paperwork.

Output: Updated hook state shape, banner component in upload-zone, toast in Home.tsx, updated STATE.md blockers, and a checkpoint task that holds the phase open until a human has verified the UI in a running dev server.
</objective>

    In `client/src/hooks/use-auto-group.ts`, add a `fallbackInfo` field to the hook's state (or whatever the existing state-shape pattern uses — do not reshape unrelated fields):

    ```typescript
    type FallbackInfo = { used: boolean; reason?: string };

    // inside the hook:
    const [fallbackInfo, setFallbackInfo] = useState<FallbackInfo>({ used: false });
    ```

    Reset to `{ used: false }` at the start of `startGrouping` alongside the other state resets (same place `setGroups([])` or equivalent is called).

    In the SSE parser block (around line 125-135 where `json.type === "group"` is handled), add a new branch:
    ```typescript
    } else if (json.type === "fallback") {
      setFallbackInfo({ used: true, reason: typeof json.reason === "string" ? json.reason : undefined });
    }
    ```

    Also handle the `done` event's new `fallbackUsed` field defensively — if fallback didn't emit an earlier event but `done` reports `fallbackUsed: true`, still flip the flag:
    ```typescript
    } else if (json.type === "done") {
      if (json.fallbackUsed === true) {
        setFallbackInfo((prev) => prev.used ? prev : { used: true });
      }
      // ... existing done handling
    }
    ```

    Expose `fallbackInfo` in the hook's return value alongside the existing fields (groups, isGrouping, etc.).
