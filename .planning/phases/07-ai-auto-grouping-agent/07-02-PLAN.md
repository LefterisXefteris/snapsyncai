Create a new hook at `client/src/hooks/use-auto-group.ts` that consumes the SSE auto-grouping endpoint.

**Hook signature:**
```typescript
interface AutoGroupResult {
  label: string;
  imageIndices: number[];
  confidence: "high" | "medium" | "low";
}

interface UseAutoGroupReturn {
  startGrouping: (files: FileItem[], productContext?: string) => void;
  isGrouping: boolean;
  groups: AutoGroupResult[];        // accumulated groups as they stream in
  totalGroups: number | null;       // set when "done" event arrives
  error: string | null;
  cancel: () => void;
}

export function useAutoGroup(): UseAutoGroupReturn
```

**Implementation:**
1. Use `useState` for `isGrouping`, `groups`, `totalGroups`, `error`.
2. Use `useRef` for an AbortController so `cancel()` can abort the fetch.
3. `startGrouping(files, productContext?)`:
   - Set `isGrouping=true`, `groups=[]`, `totalGroups=null`, `error=null`.
   - Convert each FileItem to base64: read `file.file` using FileReader as data URL, extract the base64 portion. Do this in parallel with `Promise.all`.
   - **Image resizing**: Before converting to base64, resize images that are larger than 1024px on their longest side using a canvas element. This keeps the request payload manageable for 200 images. Use `createImageBitmap(file.file)` to get dimensions, then if max(w,h) > 1024, scale down proportionally, draw to an offscreen canvas, and call `canvas.toBlob('image/jpeg', 0.8)` to get a compressed blob. Convert THAT to base64.
   - Build the request body: `{ images: [{ index, base64, mimeType, filename }], productContext }`.
   - POST to `api.images.autoGroup.path` with `credentials: "include"`, `signal: controller.signal`.
   - Read the response body as a ReadableStream using the same pattern as Phase 06's SSE hooks:
     ```typescript
     const reader = res.body!.getReader();
     const decoder = new TextDecoder();
     let buffer = "";
     while (true) {
       const { done, value } = await reader.read();
       if (done) break;
       buffer += decoder.decode(value, { stream: true });
       // Parse SSE events from buffer (split on \n\n, look for "data: " prefix)
       const lines = buffer.split("\n\n");
       buffer = lines.pop() || "";
       for (const line of lines) {
         if (!line.startsWith("data: ")) continue;
         const json = JSON.parse(line.slice(6));
         if (json.type === "group") {
           setGroups(prev => [...prev, json.group]);
         } else if (json.type === "done") {
           setTotalGroups(json.totalGroups);
         } else if (json.type === "error") {
           setError(json.message);
         }
       }
     }
     ```
   - On completion or error, set `isGrouping=false`.
   - On AbortError, silently stop (user cancelled).

4. `cancel()`: Call `controllerRef.current?.abort()`, set `isGrouping=false`.

**Important:** Do NOT use `useCallback` on `startGrouping` -- it captures `files` as a parameter, not from state. Keep it simple.
