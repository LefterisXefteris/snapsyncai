  <how-to-verify>
    Open the app in a browser and test each success criterion:

    **SC-1 — Persistence across refresh:**
    1. Go to the upload screen
    2. Drop 4-6 images — they group automatically
    3. Manually drag one image to a different group
    4. Refresh the page (Cmd+R / F5)
    5. EXPECTED: Groups reappear exactly as you left them (same images, same grouping, no prompt)

    **SC-2 — IndexedDB as blob storage with 24h expiry:**
    1. Open DevTools > Application tab > Storage > IndexedDB
    2. Expand "staged-images-db" > "blobs" store
    3. EXPECTED: One record per staged image; each record has a `blob` field (not a data URL string) and a `savedAt` timestamp

    **SC-3 — Full card drop target:**
    1. Start dragging a thumbnail
    2. Hover over the empty whitespace inside a group card (below the images, not on a thumbnail)
    3. EXPECTED: The whole card highlights with the primary color overlay (not just a narrow strip)

    **SC-4 — Multi-select drag:**
    1. Click one thumbnail — it gets a blue ring
    2. Click two more thumbnails — all three show blue rings
    3. Drag one of the selected thumbnails to a different group card
    4. EXPECTED: All three selected images move together; drag ghost shows "3" badge

    **SC-5 — Hero image = first image:**
    1. Look at any group with multiple images
    2. The first image (leftmost, larger) is the hero slot
    3. Drag the second image to a different group, then drag it BACK and drop it
    4. EXPECTED: It appears after the current images — reordering within the group changes which image is first. (Within-group reorder via drag is not yet implemented — the hero is simply items[0])

    **SC-6 — Per-group max control:**
    1. Find the `− [N] +` control in a group card header
    2. Click `+` twice — EXPECTED: the number between the buttons increases by 2
    3. Click `−` once — EXPECTED: decreases by 1
    4. Click `+` on a DIFFERENT group — EXPECTED: only that group's number changes

    Report: "approved" if all pass, or describe specific failures.
  </how-to-verify>
