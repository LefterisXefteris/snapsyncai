# Prepaid credits replace the £0.70 per-write charge

Money for AI listing copy is a **Credit** balance, not a Stripe charge on each Accept. Catalogue, facts, typed listing copy, Push, Import, and Inventory stay free. One Credit is spent when an Accept lands for first generate, listing copy refresh, a per-field regenerate after an Accept, or one Bulk SEO product — Propose and Bulk SEO Start do not spend. Each shop gets **three free** Credits for life, then buys a fixed pack of **10 (£7), 50 (£30), or 100 (£55)** — larger packs cost less per Credit than £0.70. An empty balance refuses the Accept; there is no £0.70 fallback. Pack checkout is consent; Accept does not confirm again. Spend only when Accept lands (deduct in the same transaction as the save). Stale regenerate stays free. Existing Plan and Leftover weekly run to period end without spending Credits, then follow these rules. New checkouts are not a Plan and not Leftover weekly.

This supersedes the per-write meter in [0040](0040-free-workspace-listing-copy-writes-at-seventy-pence.md).

**Considered:** keep £0.70 per Accept and only rename “write” to “credit” in the UI (rejected — sellers must buy a balance, not pay per land); hybrid packs plus £0.70 fallback (rejected — two money paths); charge Bulk SEO Start or propose (rejected — proposals the seller never Accepts should not burn Credits); drop the three free (rejected — same onboarding as ADR 0040); custom pack amounts (rejected — three fixed sizes for v1); credit balance on the seller across shops (rejected — shop boundary matches the old write meter); confirm again on first paid Accept after a pack (rejected — checkout is enough).
