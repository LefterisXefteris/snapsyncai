# Conversation talk does not spend Allowance

Model calls that only talk — a stock question, a job offer, a refusal — do not spend a **listing-copy write** (and did not spend **Allowance** when that meter existed). A write is still only a landed Accept of listing-copy AI, spent by the existing job when that result lands; Website Publish is not a write ([0040](0040-free-workspace-listing-copy-writes-at-seventy-pence.md)). There is no separate cap on talk. We rejected metering the **conversation** itself, and we rejected a second limit beside the write meter.
