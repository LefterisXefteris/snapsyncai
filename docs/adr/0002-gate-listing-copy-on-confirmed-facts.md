# Gate listing copy on confirmed product facts

SnapSync used to write titles and descriptions from the product photo, which invented materials and safety claims. Listing copy (title, description, SEO, AEO) now waits until the seller confirms product facts. The unpaid title teaser goes away; classification (category / product type) may still run from the photo. We accepted a slower conversion funnel rather than shipping invented composition.

Existing listing copy is grandfathered. Publish is not blocked. Editing facts marks listing copy stale until the seller regenerates.
