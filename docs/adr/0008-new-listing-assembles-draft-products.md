# New listing assembles draft products, not a photo pool

On New listing, each photo starts as its own **draft product**. Grouping extracts selected photos onto a new draft product; it does not create **variants**. Confirm creates every draft still on the canvas.

We rejected a photo pool (one-shot listings would need an extra “make product” step), join-heuristics (unclear which draft “won”), and vision auto-group (wrong merges are worse than extra clicks). Drag is a shortcut, not the only way to assemble.
