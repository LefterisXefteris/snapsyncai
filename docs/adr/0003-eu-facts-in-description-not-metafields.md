# Put EU product facts in the Shopify description in v1

Shopify’s GPSR guidance allows required information in the product description or in metafields (warnings via Disclosures metaobjects). SnapSync does not write metafields today, and metafields are invisible until a theme renders them. v1 therefore inserts fibre composition, care, and GPSR identity as blocks in the description HTML we already publish, which is visible before purchase on every theme. Metafields and Disclosures are a later change, not this slice.
