# Product page is the SnapSync product, not a channel admin

The product page holds product facts, listing copy, and selling for first listing from photos. Push maps that record onto a channel. Channel leftovers (collections, shipping/weight, theme template, vendor) stay in that channel’s admin. We rejected cloning Shopify admin — it fights Wix and Vinted — and rejected growing Shopify-only fields onto the page under a “hybrid.” WooCommerce is not a channel yet and does not shape the page. First listing is single-SKU; variant editing is a later product job, not a field under listing copy.
