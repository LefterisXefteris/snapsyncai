# Chat runs the act, and Undo lasts nine seconds

A missing input used to be asked, and nothing ran, so Chat stalled on confirmation. A message that already carries the inputs runs that act on the same turn. Chat does not ask the seller to confirm, and it does not invent a price, a quantity, a fibre, or a legal fact. One missing input is still asked, and nothing runs. **Undo** is a control on the reply that landed the write, shown for 9 seconds. Each such reply keeps its own control until that reply’s 9 seconds end. It puts back the previous value of that reply’s Selling, Inventory, typed listing copy, confirmed facts, publications, or Shop GPSR. A reload clears the control and leaves the write, because Undo is not stored on the shop. Push, Go live, delete, Import, and Accept still run in that one turn, and they have no Undo: nine seconds cannot unsend a Channel or unspend a Credit. [0050](./0050-chat-is-a-card-beside-the-api.md) still holds for the page’s gates, Credits, and the acts that stay in the browser.

We rejected a Selling-only trial, a typed “undo”, one shared control that the next message clears, storing Undo on the shop, and rewinding Push, Go live, delete, Import, or Accept.
