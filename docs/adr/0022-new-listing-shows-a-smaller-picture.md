# New listing shows a smaller picture than the staged file

On **New listing**, each cell and the selection dock show a smaller picture kept with the staged roll, so coming back does not decode the camera file again. **Create** still sends the original file. A photo that cannot be shrunk shows the original file. The first open of a roll staged before this picture existed may hitch once while those pictures are made.

We rejected decoding the original file in every cell, and converting HEIC in this pass. This is not a new kind of **photo**, not the **thumbnail**, and not a preview.
