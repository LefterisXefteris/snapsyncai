# A missing Shopify shop is claimed by the seller

A seller with no Shopify Channel may have SnapSync ask Shopify to open a shop. The seller **claims** it on their own Shopify account; until then it is not their Channel. A shop they already own is still connected by install. One Plan is still one Shopify shop. The website stays a Lovable snapshot after products are pushed, and that handoff still receives no Shopify credentials. The conversation never chooses which shop an admin token belongs to, and it never sees that token; the server binds the shop to the signed-in seller. Channel claim opens the shop only. It does not add a SnapSync publication; go live stays the Online Store. We rejected Storefront MCP and the Shopify.dev MCP as the way to open a shop, and we rejected turning SnapSync into its own publication on that shop.
