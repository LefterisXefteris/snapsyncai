# Bulk SEO is a seller-started search-demand pack, not an agent

Sellers asked for an agent that scans the internet for similar products and applies weekly SEO changes. **Bulk SEO** is the catalogue job: the seller starts a run, SnapSync proposes listing-copy changes from **search demand**, and accept persists those fields without Push. We rejected a scheduled or autonomous agent, scraping competitor listings (ADR 0012), replacing **listing copy refresh**, and naming this Agentic SEO.
