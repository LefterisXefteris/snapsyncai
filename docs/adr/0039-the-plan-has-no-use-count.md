# The Plan has no use count

The Plan stays **£19/month** or **£190/year** for one seller and one Shopify shop. Listing-copy writes and website Publish are included: no 20-use Allowance, no £0.70 Overflow, and no confirm on the next one. Annual is the same Plan for a cheaper fee. Someone already on the Plan is not charged for the next write or Publish; 70p invoice items already created stay until that invoice closes, and the fee already paid is not refunded. **Leftover weekly** stays £4/week with a 30-use hard stop and no extra charge until the seller cancels or switches. Without a Plan those jobs stay blocked. Confirming facts and talk stay free. This supersedes the Allowance meter in [ADR 0014](0014-plan-and-allowance-not-weekly-cap.md), and supersedes [ADR 0020](0020-overflow-is-seventy-pence.md) and [ADR 0021](0021-overflow-confirm-first-extra.md). Talk still does not count ([ADR 0032](0032-conversation-talk-does-not-spend-allowance.md)).

**Considered:** calling the 20 “unlimited” while keeping the meter (rejected — the meter is the limit); giving Leftover weekly the same inclusion (rejected — £4/week would be the better deal); refunding queued 70p lines or unused annual uses (rejected — stop new charges, leave money already committed); a quiet fair-use cap (rejected — a later cap would be a new decision).
