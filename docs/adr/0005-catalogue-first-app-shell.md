# Catalogue-first app shell

SnapSync is a textile-first workspace across Shopify, Wix, and Vinted, not a photo-to-listing tool. The authenticated app is a persistent nav whose home is **Products** (the catalogue). **New listing** (photos), **Import**, **Inventory**, **Bulk SEO**, and **Settings** are destinations; listing from photos is one job, not the chrome. We rejected keeping upload as the default canvas, and rejected shipping fake tables for jobs with no backend — those pages are honest empty states until the APIs exist.
