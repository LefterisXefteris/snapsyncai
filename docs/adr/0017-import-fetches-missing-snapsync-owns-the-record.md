# Import fetches missing Channel products; SnapSync then owns the record

Sellers asked to maintain the shop — orders, collections, shipping, theme, a second Channel — before the Shopify catalogue lives here. **Import** is the next job: one seller-started fetch of Shopify products whose Channel product id is not in the catalogue. The first fetch copies identity, photos, listing copy, selling, variants (visible), Draft/Active, and publications; **product facts** stay unconfirmed; Channel listing copy is grandfathered (ADR 0002). After that SnapSync owns facts, listing copy, selling, and variants; Push/Sync writes to Shopify; a re-run skips rows already here. Refresh and Bulk SEO still wait on confirmed facts. **Variant** selling is price, compare-at, cost, SKU, and barcode — not quantity; **Inventory** Autopilot owns stock when it is on. Wix and Vinted wait. We rejected cloning Shopify admin (ADR 0009), a Shopify mirror or two-way merge, a schedule, Bulk SEO–style ticks, guessed legal facts from the Channel description, a twin row for the same Channel id, and Sync pushing a second stock number over Autopilot.
