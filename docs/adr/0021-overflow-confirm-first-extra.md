# First Overflow of the month needs a server confirm

Overflow is still post-pay on the Plan invoice at £0.70 (ADR 0020), not a pack and not a top-up. The first extra Allowance use in a UTC calendar month does not land until the seller confirms that write; later extras that month stay silent. The Plan module decides whether this job would spend as overflow and whether confirm is required — the SPA does not compute used ≥ 20. Ack is stored only when that overflow spend lands. Leftover weekly, free, local bypass, streams, and stale regenerate do not confirm.

**Considered:** a prepaid 70p pack (rejected — credits stay dead); confirm every extra write (rejected — a photoshoot weekend is not 15 dialogs); client-only dialog (rejected — ADR 0007, this is a charge); 70p without a Plan (rejected — ADR 0020).
