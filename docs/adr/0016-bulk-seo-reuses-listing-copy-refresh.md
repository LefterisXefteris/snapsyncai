# Bulk SEO reuses listing copy refresh per selected product

A Bulk SEO run is the seller picking catalogue products on **Bulk SEO** (not on Products) that already pass **listing copy refresh**, then that module once per product: same search-demand adapter, same four fields, same accept rules, one demand snapshot each. Accept is per product and spends Allowance when that write lands. One product with empty demand or a failed rewrite does not fail the pack. There is no second product cap; Start shows how many uses accepting all would spend. We rejected a LangGraph agent, Langfuse as part of this job, a shop-wide or week-cached demand snapshot, rewriting title or AEO, all-or-nothing accept, picking from the catalogue bar, failing the whole run on one SKU, and a hard cap that re-rations Allowance.
